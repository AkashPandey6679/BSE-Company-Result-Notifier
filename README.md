1.	Install VS Code 
2.	Install the latest version of Python or Python Ver. 3.13.
3.	Open "Telegram Quarterly Result Notifier.py" and press CTRL + SHIFT + P, type: "Python: Select Interpreter," click it, and choose the Python version.
4.	After that, in the terminal type "pip install requests" and press enter.
5.	After that, when the installation is done, run the code, and the results notification will be sent directly to the Telegram group.
6.	Access to the Telegram group to make changes is on the green iPhone


Note: - BSE API sends the previous day's results announcement notification all at once, anytime the code is running, so ignore if you see around 15-20 notifications at once.
